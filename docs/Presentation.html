How it works

Sensor sensitivity = 85%
Sensor specificity = 90%

posterior = likelihood × prior ÷ evidence

Bayes uses an imperfect sensor's signal to revise the current probability.

These probabilities are teaching assumptions, not real sensor readings04 / 07
04 / Decision making

MDP — DRIVE or RECHECK?

Two states: FREE and OCCUPIED. Two actions: DRIVE and RECHECK.

Q(s,a) = R(s,a) + γ Σ P(s'|s,a) V(s')   ·   γ = 0.60

DRIVE

Go now. Reward is high if the bay is free, but low if it is occupied.

RECHECK

Spend a little time getting more information before going.

Decision: compare belief-weighted expected scores and select the greater value.
