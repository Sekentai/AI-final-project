## Contents

- `app.py`, `parking_ai.py`, `web/` — working local web app
- `tests/` — unit tests and optional browser smoke test
- `assets/` — example screenshots from all three scenarios
- `docs/Technical_Report.docx` — project report
- `docs/Presentation.pptx` — seven-slide presentation
- `docs/AI_Use_Declaration.docx` — AI contribution disclosure
- `docs/Team_Contribution_Statement.docx` — contribution form; fill only real individual contributions
- `docs/Demo_and_Defense_Script.md` — demo narration and defense notes

The project demonstrates BFS, Bayesian inference, and a one-step MDP independently on three simulated parking layouts. **It does not use real occupancy data or make real parking recommendations.**

## Running

On Windows, run `run_windows.bat`, or use `python app.py` (Python 3.9+), then open http://127.0.0.1:8765/. GitHub is the code/document-sharing location, not a hosted application in itself.
